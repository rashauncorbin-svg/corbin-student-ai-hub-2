# Corbin Command Center — Foundation Preview

A separate internal operating workspace for GVE Educator Solutions. This is intentionally distinct from the student-facing Corbin Student AI Hub and the teacher-facing command center embedded in that hub.

## Product direction

The Command Center is intended to become the living operating system and source of truth for GVE's educational products and intellectual property. It must be expandable, editable, searchable, reusable, scalable, and continuously updated as new packages are built.

## Initial modules

- Founder overview and operating dashboard
- Portfolio and product catalog
- Production Studio and build pipeline
- Master Content Library
- Course Hubs
- Corbin Learning System (CLS) Library
- Template Vault
- Teachers and Clients
- Archive and version history

## Operating principles

1. Preserve approved master assets; never silently overwrite them.
2. Keep client-specific deliverables distinct from reusable master IP.
3. Allow packages to be duplicated, upgraded, and connected to source materials.
4. Maintain a searchable source of truth across courses, products, and assets.
5. Separate internal operations from any future client-facing portal.
6. Add role-based access, audit history, backups, and shared persistence before real business or client records are entered.

## Current implementation status

This branch contains a navigable frontend foundation with illustrative records only. It is not yet connected to a database, authentication provider, file storage, or live GVE records. Do not enter confidential client information or business records in this preview.

## Development direction

The next engineering stages are: information architecture and workflows; identity and permissions; persistent relational data model; file and version management; search and cross-linking; production and client workflows; reporting and automation; deployment and security validation.
